### 📌 Описание предметной области
Программа представляет собой файловую базу данных для учета расписания пригородных электропоездов. 
Реализована на языке **Java** с графическим интерфейсом на базе **Java Swing**. 
В качестве хранилища данных используются бинарные файлы, без применения сторонних СУБД.

### 🏗 Архитектура и структура 
Для обеспечения высокой производительности (сложности O(1) для ключевых операций) используется:
1. **`RandomAccessFile`** для прямого доступа к записям в файле `trains.db`.
2. **Фиксированный размер записи (102 байта)**, что позволяет вычислять смещение (offset) для любой записи.
3. **Индексный файл `trains.idx`** на основе `HashMap<Integer, Long>`, где ключ — это ID поезда, а значение — его байтовое смещение в основном файле.
4. Запрет на загрузку всей БД в оперативную память (массивы/списки используются только для вывода в GUI).

**Поля базы данных:**
| Поле | Тип | Размер (байт) | Описание |
|---|---|---|---|
| `id` | `int` | 4 | Уникальный идентификатор (Ключевое поле) |
| `trainNumber` | `String` | 20 | Номер поезда (10 символов * 2 байта) |
| `destination` | `String` | 120 | Станция назначения (60 символов * 2 байта) |
| `departureTime` | `String` | 10 | Время отправления ЧЧ:ММ (5 символов * 2 байта) |
| `price` | `double` | 8 | Стоимость билета |

## ⏱ Асимптотическая сложность
Благодаря использованию индексации и `RandomAccessFile`:
* **Поиск по ID (ключу)**: **O(1)** (константное время).
* **Добавление записи**: **O(1)** (запись в конец файла).
* **Удаление записи**: **O(1)** (перезапись первых 4 байт маркером `-1`).
* **Редактирование записи**: **O(1)**.
* **Очистка БД**: **O(1)** (метод `setLength(0)`).
* **Поиск по направлению (неключевому полю)**: **O(N)** (линейный перебор всех записей).
